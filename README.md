# Homepage
A simple, minimalist, modern, and distraction-free browser homepage, featuring responsive design, automatic light and dark mode switching, without using any external libraries — just what a browser homepage should be.

Choose from 11 built-in search engines:
 - **DuckDuckGo** (default)
 - Bing
 - Brave
 - Ecosia
 - Google
 - Karma
 - Qwant
 - Reddit
 - Wikipedia
 - Yahoo
 - YouTube

Using the **Settings** menu (accessible from the hamburger button in the top-left corner), you can:
- Select your preferred search engine
- If none of them fit your needs, use a custom search engine
- Change the search placeholder text (when using a custom search engine)
- Show or hide individual quick links
- Toggle the divider beneath the search bar for an even more minimalist look
- 
## Custom Search Engine

The latest version allows you to use your own search engine by putting its base URL. For example, DuckDuckGo's base URL is `https://duckduckgo.com/?q=` and Google's one is `https://www.google.com/search?q=`. Remove all metadata and unnecessary parameters and include *only* its base URL.

## Quick Links

The quick links can be individually enabled or disabled. By default, they are grouped into three categories:

- **Coding:** GitHub, Stack Overflow
- **Productivity:** LinkedIn, Wikipedia
- **Leisure:** YouTube, Reddit, Strava

## Keyboard Shortcuts

| Shortcut | Action |
|---|---|
| `Ctrl + K` | Focus search bar |
| `Ctrl + .` | Toggle settings menu |
| `Esc` | Close settings menu |
